# Scene Switcher Menu

Group your scenes and switch between them from a menu that opens right where your mouse is.

Some of my files end up with lots of scenes. I wanted to put them in groups and bring the groups and the scene switch right to where my mouse is, with a shortcut, instead of going up to the top bar every time.

## Features

- **Shortcut everywhere**: Ctrl+Alt+Shift+S by default, in every editor and mode.
- **Groups** that open as submenus, saved in the .blend.
- **Optional submenu mode**: each scene opens its own submenu.
- Scenes whose name starts with a dot are hidden from the menu.

## How to use

1. Press **Ctrl+Alt+Shift+S** in any editor. The menu opens under your mouse.
2. Click a scene to switch to it. The current one has a check mark.
3. Create a group from the menu and give it a name. Groups show up as submenus.
4. To move a scene into a group, Shift, Ctrl or Cmd + click it and pick the group. You can also add a new scene directly inside a group.
5. Rename or delete groups from the same menu.
6. To change the shortcut or turn on the submenu mode, go to **Edit > Preferences > Add-ons > Scene Switcher Menu**.

Requires Blender 4.0 or newer. Install `nakan_scene_switcher.py`.
