# Nakan Text Animator Tools

After Effects-style text animators on regular, editable Text objects: range selector, opacity, position, scale, rotation, tracking (anchored to the text alignment or to the left, center or right of each line) and material fill. Find it in **Properties > Text (Object Data)**.

Requires Blender 5.0 or newer. Install `nakan_text_animator_tools.py`.
