# Nakan Collect Files

Gathers everything a .blend needs so it can be archived or sent. Linked libraries become local, and textures, UDIMs, Geometry Nodes bakes and IES/OSL files are packed inside the .blend. VDB, Alembic/USD, videos, image sequences and fluid/ocean/physics caches are copied to a `<name>_files` folder next to it. Unpack does the reverse. Find it in **File > External Data > Nakan Collect Files**.

Requires Blender 4.2 or newer. Install `nakan_collect_files.py`.
