# Add Geometry Nodes Object

A simple Add > Geometry Nodes object. A few clicks fewer every time you start a node setup.

I think Blender should have a simple way to add a Geometry Nodes object directly. Starting from scratch usually means adding a cube, deleting its vertices, adding a modifier and clicking New. This does it in one step.

## How to use

1. In the 3D View, press **Shift+A** and choose **Geometry Nodes**.
2. A new object appears at the 3D cursor, with an empty mesh, a Geometry Nodes modifier and a fresh node group with Group Input connected to Group Output.
3. Open a Geometry Node Editor and start adding nodes.
4. Rename the node group in the editor header if you want to reuse it later.

Requires Blender 4.0 or newer. Install `add_geometry_nodes_object.py`.
